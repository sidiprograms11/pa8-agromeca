# Visuels autorisés dans le portfolio

Vous pouvez ajouter :

1. Un schéma d'architecture simplifié et anonymisé.
2. Une matrice de risques récapitulative sans actifs ni scores détaillés.
3. Un diagramme RACI anonymisé.
4. Des captures de tableau de bord de supervision avec données fictives.

Avant publication, retirez les adresses IP, FQDN, noms de VM, identifiants, domaines internes, adresses e-mail, signatures, règles, journaux détaillés et tout élément de configuration.
