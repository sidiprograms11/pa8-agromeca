# Publication responsable

Ce dépôt est une synthèse publique d'un projet académique. Ne publiez pas de document interne brut, de plan d'adressage, de règle de filtrage, de configuration VPN, de capture contenant des identifiants, de nom d'hôte, de certificat, de secret ou de données personnelles.

Si une information sensible apparaît par erreur, ouvrez une issue privée ou contactez le propriétaire du dépôt avant toute divulgation publique.
